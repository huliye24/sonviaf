## External product

Sonviaf 是 AI 音乐管理软件。它产生于 AI 音乐数量爆发之后：生成工具让音乐快速出现，用户因此需要
管理作品来源、打开声音结构、得到可演唱的伴奏，并让人的声音形成新的 Performance。

首要体验为：

```text
Upload → Separate → Sing
```

这条体验描述目标关系，不虚构运行状态。当前网页仅是本地交互样机：文件未上传，分轨未执行，录音、
Core 处理、云同步与发布均未接通。

## Production relationship

Sonviaf 管理的基本对象不是孤立音频文件，而是有来源的 Work 及其后续演唱关系：

```text
Work 1 → N Performance 1 → N Vocal Take
```

生成提供源素材；分轨使结构可理解和可处理；真人演唱把音乐带入新的身份表达。每次演唱增加关系，
而不是覆盖原作。用户持有原始资产、导出权与删除权。

## Name meaning

- **SON** — sonic sound，声音本体。
- **VIA** — 经由人的选择、分解、演唱与验证。
- **F** — forward，作品继续向前。

## Invariants

1. One Core：声音分析、分轨、处理、Judge 与验证只有一套权威。
2. Original preserved：Work 与原始 Take 不被派生结果覆盖。
3. Generated is the beginning：Provider 输出不能自证完成。
4. Honest capability：未实现能力必须显示 Preview、Pending 或明确失败状态。
5. User asset authority：可发现不等于平台拥有。
6. No silent history rewrite：Moodify 历史证据保留原名。
